# Portfolio — ZOA ELEMBE BENJAMIN

Site statique responsive construit à partir des documents, cartes et captures fournis.

## Déploiement gratuit

Le dossier `site/` peut être publié tel quel sur GitHub Pages, Netlify ou Vercel.

### GitHub Pages
1. Créer un dépôt GitHub.
2. Importer le contenu de `site/` à la racine.
3. Dans **Settings → Pages**, choisir la branche principale et le dossier `/ (root)`.
4. Enregistrer : GitHub Pages générera l'adresse du site.

Aucune base de données ni serveur n'est nécessaire pour cette version.
